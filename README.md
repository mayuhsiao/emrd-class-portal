# 臺科大 EMRD × SEMI-EMRD 班級入口

班級入口網站：開場輪播活動照片，也放了臺科大形象動畫、活動花絮、同學任職企業 Logo 牆，並連到年終宴會的幸運抽獎與交換禮物。純前端網頁，**不需要安裝、不需要網路**，雙擊 `index.html` 即可使用（建議用 Chrome 或 Edge）。

| 頁面 | 內容 |
| --- | --- |
| `index.html` | 班級入口首頁 |
| `lucky-draw.html` | 抽獎程式。`?mode=prize` 直接進抽禮物、`?mode=exchange` 直接進交換禮物 |

## 首頁內容

| 區塊 | 說明 |
| --- | --- |
| 活動照片輪播 | 10 張精選照片加 1 段影片，照片 6.5 秒、影片 15 秒換下一張。可暫停、按方向鍵或滑動切換；頁面捲走或切到別的分頁時會自動暫停 |
| 年終宴會 | 幸運抽獎與交換禮物的入口，卡片上顯示目前的抽獎進度（讀取抽獎程式存的資料） |
| 臺科大影片 | `hero-bg.mp4`，靜音循環，只在看得到時播放 |
| 活動花絮 | 54 張照片，可篩選校友會 / 課堂，點開可放大瀏覽 |
| 同學任職企業 | 61 家企業 Logo，滑鼠移上去顯示公司名稱（不顯示同學姓名） |
| 班級網站 | 連到 [emrd115.netlify.app](https://emrd115.netlify.app/) 各頁面與課程筆記 |

Windows 關閉「動畫效果」時，瀏覽器會要求網站減少動態。此時輪播和影片照常運作，只拿掉照片推近幅度、光掃、卡片傾斜和影片放大效果。

## 更新照片與素材

照片後製與輸出由 `tools/` 的兩支 Python 程式負責：

- `tools/photo_grade.py`：照片調色（白平衡、補光、膚色保護、天空、色調）
- `tools/build_portal.py`：讀取 `素材/`，輸出 `assets/portal/`、`assets/video/` 和 `js/portal-data.js`

```bash
python tools/build_portal.py
```

也可以只重做其中一部分：

```bash
python tools/build_portal.py hero gallery
```

可用的項目有 `video`、`hero`、`gallery`、`logos`。輪播要用哪些照片、如何裁切，以及花絮照片清單，都在 `build_portal.py` 開頭的 `HERO`、`GALLERY`。需要的套件：Pillow、OpenCV、NumPy、pillow-heif；擷取影片畫面需要 ffmpeg。

`js/portal-data.js` 是產生出來的檔案，請勿手動修改。

`素材/` 沒有放進 git，重新輸出時本機要有這個資料夾，請另外備份。

## 放到網路上

- **只需要上傳**：`index.html`、`lucky-draw.html`、`css/`、`js/`、`assets/`、`photos/`
- **不要上傳**：`素材/`（約 320 MB 原始檔）、`tools/`、`.claude/`
- 首頁目前設定 `noindex`，搜尋引擎不會收錄。因為網站有同學與小孩的照片，要移除這項設定（`index.html` 的 `robots`）前，請先確認大家同意公開。
- 這個 repo 是公開的：`js/data.js` 有學員姓名，`photos/` 和 `assets/portal/` 有學員與小孩的照片。有人要求移除照片時，除了刪除檔案，也要清除 git 歷史，並請 GitHub 清除快取。

# 年終宴會抽獎程式

包含「交換禮物」與「抽禮物」兩種模式，名字旁邊會顯示學員照片。

## 快速開始

1. 用 Chrome / Edge 打開 `index.html`，點「幸運抽獎」或「交換禮物」（也可以直接開 `lucky-draw.html`）
2. 按 `F` 進入全螢幕，接上投影機
3. 按 `Space` 開始轉、再按一次 `Space` 停止開獎

> 瀏覽器規定：音效要在「第一次按鍵或點擊」之後才會出聲，所以第一輪按下去就會有聲音。

右上角的 **首頁** 可以回到班級入口。

## 兩種抽獎模式

| 模式 | 說明 |
| --- | --- |
| 🎁 **交換禮物** | 左邊轉出「抽獎人」，右邊轉出「抽中誰的禮物」。**保證不會抽到自己的禮物**（`抽獎人 ID !== 禮物 ID`），而且程式會預先檢查，最後一位絕對不會卡在「只剩自己的禮物」。 |
| 🏆 **抽禮物** | 一般幸運抽獎。可在上方填「本輪獎項」（例如：頭獎），會顯示在舞台與紀錄上。 |

- **抽 1 人 / 抽 2 人**：上方切換，或按鍵盤 `1`、`2`。交換禮物抽 2 人時，一次出現兩組（兩位抽獎人各抽一份禮物）。
- **🎲 隨機抽獎人 / 🔗 接力**（交換禮物專用）：
  - 隨機：每輪由轉盤抽出抽獎人。
  - 接力：上一輪「禮物被抽走的人」下一輪接著上台抽，舞台會直接顯示「下一位抽獎人」。
- **抽過自動剔除**：抽過的人（與被抽走的禮物）會直接從候選池移除，不會重複。

## 快捷鍵（簡報筆、無線數字鍵盤都能用）

| 按鍵 | 功能 |
| --- | --- |
| `Space`、`Enter`、`PageDown`、`PageUp`、方向鍵 | 開始 / 停止（開獎畫面時直接開始下一輪） |
| `1` / `2` | 一次抽 1 人 / 2 人 |
| `M` | 音效開關 |
| `B` | 背景音樂開關 |
| `F` | 全螢幕 |
| `P` | 顯示 / 隱藏右側紀錄面板 |
| `Esc` | 關閉開獎畫面或對話框 |

一般簡報筆的「下一頁 / 上一頁」送出的是 `PageDown` / `PageUp`，所以任何一顆都能開始或停止。

## 名單管理

右上角 **👥 名單**：

- 新增：輸入姓名按 Enter，可一次貼上多位（每行一位，或用逗號、頓號分隔），重複的名字會自動略過。
- 修改：直接點名字修改。
- 刪除：按 ✕ 兩下（第一下會變成「刪除?」防止誤按）。
- **恢復預設名單**：換回預設的 34 位學員。

標題可以「點兩下」修改，例如改成當天的活動名稱。

## 學員照片

轉盤、開獎畫面、紀錄、名單上，名字旁邊都會顯示照片；沒有照片的人會顯示用名字做的彩色圓形頭像。照片有兩種放法：

1. **放進 `photos` 資料夾（推薦）**：檔名用姓名，例如 `photos/林振川.jpg`（支援 .jpg / .jpeg / .png）。開啟頁面就會自動顯示，而且整個資料夾複製到現場電腦時照片會一起帶過去。
2. **在畫面上匯入**：右上角 **👥 名單** → **📷 匯入照片（可多選）**，一次選取多張照片；檔名用姓名或編號（例如 `林振川.jpg`、`01.jpg`、`01_林振川.jpg`）會自動對應。也可以點某個人的頭像單獨上傳或更換。這種方式的照片存在「這台電腦的瀏覽器」裡。

照片會自動裁成正方形（直式照片保留上半部的臉），iPhone 的 HEIC 格式請先轉成 JPG。

目前 `photos` 資料夾裡的 33 張照片取自班級網站專案 `web-emrd`（115 級成員照片），已依臉部位置裁成 360×360 的正方形；陳俊宏目前沒有照片，會顯示名字頭像。

## 紀錄、查核與匯出

右側紀錄面板：

- **🏅 中獎紀錄**：每一輪的結果（新的在最上面）。
- **🔍 名單查核**：自動檢查「沒有人抽到自己的禮物」「沒有重複」，並列出還沒抽的人、還沒被抽走的禮物，方便最後確認有沒有遺漏。
- **↶ 撤銷上一輪**：抽錯或有人不在時使用，該輪的人會回到候選池。
- **📜 總表**：放大顯示全部結果，適合最後投影給大家看。
- **⬇ 匯出 CSV**：下載結果，可直接用 Excel 開啟。
- **🗑 重置**：清除目前模式的紀錄（10 秒內可按「復原」）。
- 抽禮物模式中，得主不在現場可按該筆紀錄的「未到」：標記作廢、不放回候選池，再抽一位補上即可。

## 資料保存（localStorage）

- 名單、設定、所有抽獎結果都會**自動存在瀏覽器的 localStorage**，重新整理或關掉再開都還在。
- 開獎結果在按下「停止」的那一刻就存檔，就算動畫途中不小心重新整理，也不會變成重抽。
- 資料是跟著「這台電腦的這個瀏覽器」走的。**活動當天請用同一台電腦、同一個瀏覽器**；要留底請按「匯出 CSV」。
- 活動前測試完，記得按「重置」清掉測試紀錄。

## 其他

- 🎵 背景音樂（原創的輕快派對節奏）與所有音效都由程式即時合成，不需要音檔。
- 🗣️ 語音播報：開啟後開獎時會用中文語音唸出名字（需要電腦有中文語音，Windows 10/11 通常內建）。
- 隨機數使用瀏覽器的 `crypto.getRandomValues`，公平且無法預測。
- 字型會從 Google Fonts 載入；現場沒網路時會自動改用系統字型（微軟正黑體），功能不受影響。

## 檔案結構

```
index.html            班級入口首頁
lucky-draw.html       抽獎程式
css/portal.css        首頁樣式
css/style.css         抽獎頁樣式
js/portal.js          首頁（輪播、影片、燈箱、Logo 牆）
js/portal-data.js     首頁資料（由 tools/build_portal.py 產生）
js/data.js            預設學員名單、標題
js/logic.js           抽獎核心邏輯（不抽到自己、避免最後卡關、查核）
js/store.js           localStorage 存取
js/photos.js          學員照片（photos 資料夾偵測、匯入、頭像）
js/audio.js           音效與背景音樂（Web Audio 合成）
js/fx.js              煙火、紙花、金粉等特效
js/reel.js            3D 滾筒拉霸
js/app.js             流程、快捷鍵、紀錄、名單管理
assets/               EMRD 與臺科大標誌
assets/portal/        後製過的輪播與花絮照片、企業 Logo、影片畫面
assets/video/         臺科大形象動畫
photos/               學員照片（檔名＝姓名）
tools/                照片後製與素材輸出程式（不用上傳）
素材/                 原始素材（不用上傳）
```

預設名單在 `js/data.js` 的 `DEFAULT_NAMES`，若要改預設值可直接編輯。
